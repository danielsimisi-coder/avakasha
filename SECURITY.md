# Reporting a safety or security issue

Do not include private files, inventories, credentials or personal paths in an issue.

For a suspected data-loss issue, stop using the affected workflow, retain Trash contents, and report a minimal reproduction using synthetic files. Use GitHub's private vulnerability reporting if enabled on the repository; otherwise contact Daniel Siman Tov at [daniel.simisi@gmail.com](mailto:daniel.simisi@gmail.com) before sharing sensitive details. Public issues should contain only non-sensitive information.

This project is a beta. Only the latest release is maintained. It cannot restore files after you permanently remove them through other tools.
