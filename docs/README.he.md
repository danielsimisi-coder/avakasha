# FileTriage

**רואים קובץ, משאירים או מעבירים לפח, וממשיכים.**

כלי מקומי ל־Mac למיון קבצים גדולים, בחירה מרובה והשוואת כפילויות. בלי חשבון ובלי העלאה של הקבצים לענן.

## מתחילים

1. פותחים את האפליקציה ובוחרים תיקייה.
2. בוחרים קובץ ולוחצים רווח לצפייה.
3. חץ למטה משאיר אותו ועובר לבא.
4. ⌘ ולחיצה בוחרים קבצים נפרדים; Shift ולחיצה בוחרים רצף.
5. ״בחר הכול״ או ⌘A בוחרים את הרשימה המסוננת.
6. ⌘⌫ מעביר את הבחירה לפח, אחרי אישור שמציג מספר קבצים וגודל.
7. ⌘Z משחזר את פעולת ההעברה האחרונה במהלך ההפעלה הנוכחית, בלי לדרוס קבצים קיימים.

לחצן ימני על שורה מציג את הקובץ המקורי ב־Finder.

## כפילויות

- **זהות:** השוואת SHA-256. אפשר לבחור את העותקים הנוספים ולהשאיר אחד בכל קבוצה.
- **דומות:** השוואת תמונות מקומית, רק כשתבקש. מוצגות זו לצד זו לבדיקה; הן לא מסומנות למחיקה אוטומטית. דמיון לא אומר שתמונה מיותרת.

## דברים שחשוב לדעת

הגרסה הראשונה היא בטא, עם חתימה מקומית בלבד וללא notarization של Apple. היא אינה מוצגת כהפצה ציבורית מאושרת. אפשר לבנות מהמקור לפי ה־README הראשי. אל תבטל הגנות מערכת כדי לפתוח אותה.

סגור תוכנות שמשתמשות בקבצים לפני מחיקה. הסרת מדיה של WhatsApp עלולה להשאיר מדיה חסרה בשיחה. התוכנה לא קוראת שיחות ולא יודעת מי לקוח או מה חשוב לך. מחיקת קובץ מסונכרן לענן עלולה להסתנכרן גם לענן.

הפח אינו מתרוקן אוטומטית. אחרי סגירת האפליקציה אפשר לשחזר דרך Finder, כל עוד לא רוקנת את הפח. הגודל שמוצג הוא אומדן, ולא הבטחה לכמות המקום שתתפנה.
